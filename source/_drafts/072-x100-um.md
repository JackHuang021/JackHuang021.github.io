## 2. Mesa相关

Mesa 通常位于 Linux 图形栈的中间层：应用程序（如游戏、图形工具）通过 OpenGL/Vulkan 调用 Mesa。Mesa 与底层的内核驱动（例如 DRM/KMS）通信以实现硬件加速。Mesa支持多种图形API，包括OpenGL、Vulkan、OpenGL ES、OpenCL，这些API通过Mesa调用底层硬件来实现图形加速。

Mesa仓库地址：[https://gitlab.freedesktop.org/mesa/mesa.git](https://gitlab.freedesktop.org/mesa/mesa.git)

当没有可用的图形加速硬件时，Mesa提供软件渲染器，如llvmpipe(例如E2000下是通过llvmpipe)、swrast

### 2.1 Vulkan

Vulkan 是一种现代化的、跨平台的 低开销图形和计算 API，由 Khronos Group 开发，旨在提供更直接和高效的 GPU 控制。它是 OpenGL 的继任者，与 OpenGL 以及 Direct3D 12 类似，但在设计上强调性能、可扩展性和灵活性，尤其适用于高性能游戏、图形渲染和计算任务。

Vulkan 的每个硬件厂商（如 Intel、AMD、NVIDIA）都提供对应的 ICD驱动。这些驱动通常安装在 /usr/share/vulkan/icd.d/ 目录下。

X100的Vulkan支持用户空间驱动位于`icd.d/icdconf.json`，对应的库文件为`libVK_IMG.so`

Vulkan的调用流程：

	```
	应用程序
	└── Vulkan API 调用（libvulkan.so）
		└── Vulkan ICD 驱动（libVK_IMG.so）
				└── 内核 DRM 驱动
					└── GPU 硬件
	```

### 2.2 OpenGL

OpenGL（Open Graphics Library）是一个用于渲染 2D 和 3D 图形的跨平台、跨语言的图形 API规范。它是桌面和工作站图形渲染的标准，广泛用于游戏开发、CAD 软件、虚拟现实等领域。

Mesa 是 OpenGL 在 Linux 和其他类 UNIX 系统中的开源实现，用于提供对图形硬件的高效接口。它是 OpenGL API 的一个用户空间库，实现了标准的 OpenGL 接口，同时通过驱动程序与具体的 GPU 硬件交互。

**API前端**：Mesa 提供了一个符合 OpenGL 规范的 API 层，应用程序调用的所有 OpenGL 函数都由 Mesa 实现。库文件`libGL.so`是 Mesa 的 OpenGL 实现。

**驱动后端**：Mesa 的驱动后端实现了针对具体硬件的操作，常见的驱动类型为Gallium3D 驱动，其中X100中的用户空间驱动位于`/usr/lib/libGL_PVR_MESA.so`，为X100 的 Mesa OpenGL 3.3 实现库

### 2.3 OpenGL ES和EGL

OpenGL ES（OpenGL for Embedded Systems）是 OpenGL 的子集，专门为 嵌入式和移动设备 设计，广泛应用于智能手机、平板电脑、嵌入式系统和物联网设备。通常与 EGL 一起使用，EGL 是用于在 OpenGL ES 和 底层窗口系统 之间建立桥梁的 API，负责图形上下文管理、表面创建和同步。它同样由 Khronos Group 维护。

Mesa 提供了 libGLESv1_CM.so 和 libGLESv2.so 等库，这些库分别实现了 OpenGL ES 1.x 和 OpenGL ES 2.x/3.x 的功能。这些库是与 OpenGL ES 标准兼容的用户空间实现。Mesa 还提供了对 EGL 的实现，管理 OpenGL ES 上下文和窗口系统的交互。

Mesa中对OpenGL ES的支持与OpenGL的支持类似。其中X100中的用户空间驱动位于`/usr/lib/libGLESv2_PVR_MESA.so`，为X100 的 Mesa OpenGLES 2.0 实现库。

**Mesa 中的 OpenGL ES 调用流程：**

	```
	应用程序
	└── OpenGL ES API 调用（libGLESv2.so）
		└── Mesa 的 OpenGL ES 前端
			└── Gallium3D 驱动
				└── 内核 DRM 驱动
	```

### 2.4 OpenCL

OpenCL(Open Computing Language) 是一个由 Khronos Group 维护的开源框架，用于开发跨平台的并行计算应用程序，尤其是针对 CPU、GPU、加速器和其他处理器的计算。它为开发者提供了一个统一的接口来访问多种计算设备，使得程序能够利用计算设备的多核架构执行高效的计算任务。OpenCL 提供的编程模型允许开发者将任务分解成多个并行执行的部分，从而提高计算效率。

Mesa 通过 clover 驱动支持 OpenCL，它提供了与 OpenCL 兼容的计算支持，允许开发者在支持的硬件上运行 OpenCL 程序。clover 是 Mesa 中一个实现 OpenCL 的模块，主要提供对 OpenCL 1.x 规范的支持，其利用Gallium3D 驱动与硬件进行交互。其中X100的OpenCL用户层驱动为`libPVROCL.so`

### 2.5 DRI（Direct Rendering Infrastructure）

DRI 驱动 是图形硬件与 Mesa 驱动之间的桥梁，负责在内核层面实现硬件的直接访问，Mesa 通过 Gallium3D 与 DRI 驱动配合使用，实现对不同 GPU 的支持。其中X100的DRI驱动位于`/usr/local/lib/dri/pvr_dri.so`

### 2.6 内核驱动与Mesa交互的中间层 libsrv_um.so

X100 GPU用户层核心库。该库与GPU内核驱动`pvrsrvkm.ko`和GPU固件`/lib/firmware/rgx.fw.30.3.816.20`进行交互,调用GPU硬件。

### 2.7 X100 Mesa的适配

要让 X100 支持 Mesa 中的 OpenGL、Vulkan、OpenGL ES 和 OpenCL，需要进行下面用户空间驱动的适配：

2. Vulkan用户空间驱动

## 3 xserver相关

X100对xorg相关的修改源码位于x100-um仓库的x100-ddx目录下

### 3.1 xorg modesetting driver

modesetting_drv.so 是 Xorg 的一种显卡驱动程序模块，专注于利用 Linux 内核的 KMS（Kernel Mode Setting） 功能来设置显示模式和管理显示器。它是 Xorg 服务器中一个通用的、硬件无关的驱动程序，主要用于支持没有专用 Xorg 驱动程序的 GPU。在系统中位于`/usr/local/lib/xorg/modules/drivers/modesetting_drv.so`，其源码位于`xserver/hw/xfree86/drivers/modesetting`

### 3.2 Glamor

Glamor 是一个基于 OpenGL 的 2D 加速库，专为 Xorg 图形服务器设计。它通过 OpenGL 接口提供高效的 2D 图形渲染功能，替代传统 Xorg 驱动中的手动加速路径，减少对硬件特定代码的依赖。Glamor 在现代 Linux 图形栈中发挥了重要作用，特别是在使用通用驱动程序（如 modesetting 驱动）时。X100的Glamor适配库位于`/usr/local/lib/xorg/modules/libglamoregl.so`，其修改的源码位于x100-um仓库的x100-ddx目录下

### 3.3 X100 ddx驱动

DDX（Device Dependent X）驱动 是 Xorg 图形服务器架构中的一个核心组件，它负责将 Xorg 图形服务器与具体的硬件设备（如显示器、显卡、输入设备等）连接起来。DDX 驱动实现了与硬件的交互，包括图形渲染、输入设备事件的处理、显示管理等。简而言之，DDX 驱动提供了一个 Xorg 服务器与底层硬件设备之间的桥梁。

X100的DDX驱动位于`usr/lib/xorg/modules/drivers/pvr_drv.so`
