## 介绍

+ WLED项目官网地址：[https://kno.wled.ge/](https://kno.wled.ge/)
+ WLED项目仓库地址：[https://github.com/wled/WLED](https://github.com/wled/WLED)
+ WLED灯带电源计算网址：[https://wled-calculator.github.io/](https://wled-calculator.github.io/)

### 支持的功能

+ 使用 WS2812FX 库，集成超过100中效果
+ 使用 FastLED 库，50中调色板
+ ES8266 最大支持3组LED输出，ESP32 最大支持10组LED输出
+ 支持RGBW类型的灯带
+ 支持保存250组预设，支持循环预设效果
+ 可以通过API调用预设效果
+ 支持OTA
+ 支持模拟时钟显示
+ 支持文件系统

### 控制接口

+ Android 和 IOS 客户端软件（官方应用为 WLED native）
+ JSON 和 HTTP request API 控制
+ MQTT 控制
+ Blynk IOT 控制
+ E1.31, Art-Net, DDP and TPM2.net
+ Hyperion （流光溢彩类的控制）
+ UDP Realtime
+ Alexa 语音控制
+ 与飞利浦 HUE 同步
+ 多个 WLED 设备同步
+ 红外遥控
+ 定时控制
